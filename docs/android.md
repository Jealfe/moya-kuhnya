# Android — «Моя кухня»

Android использует тот же каталог `public/` и сборку `dist/`, что и GitHub Pages.
Идентификатор пакета: `ru.jealfe.moyakuhnya`, Android 7.0/API 24 или новее.
Node.js >=22, JDK 21, Android SDK Platform 36, Build Tools 36.0.0.
Gradle 8.14.3 скачивается wrapper-скриптом автоматически. Capacitor закреплён в package-lock.json.

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run build
npm run android:sync
npm run android:apk
npm run android:open
```

Укажите SDK через `ANDROID_HOME` или `sdk.dir` в локальном `android/local.properties`.
APK: `android/app/build/outputs/apk/debug/app-debug.apk`.
Скопируйте его на телефон и разрешите установку приложений выбранному файловому менеджеру.
При наличии ADB: `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`.
Эмулятор не требуется. Команды выше его не запускают.

Обновляйте установкой поверх прежнего APK с тем же applicationId и той же подписью.
Не удаляйте приложение перед обновлением. Для обновлений сохраняйте свой debug keystore;
на другом компьютере подпись по умолчанию будет другой. Перед переустановкой сделайте JSON-копию.
Релизную подпись храните вне репозитория. Очистка данных приложения удаляет его локальные данные.

## Перенос из Chrome

1. В веб-версии: Настройки → Скачать копию.
2. Перенесите JSON на телефон.
3. В APK: Настройки → Восстановить из файла → выберите JSON → подтвердите замену.
4. Проверьте дневник, фотографии, покупки и локальные рецепты.

Chrome и APK имеют разные IndexedDB. Автоматически данные между ними не передаются.
Файлы JSON и фотографии выбираются штатным файловым выбором Android WebView.
Экспорт JSON в APK использует ACTION_CREATE_DOCUMENT (Storage Access Framework), без разрешения
доступа ко всему накопителю. Пользователь выбирает папку и имя файла.
Service Worker работает только в браузере. В APK интерфейс, схемы, рецепты и иллюстрации
поставляются локально. «Проверить GitHub» загружает новые рецепты по HTTPS вручную.

## Проверить на телефоне

- Каталог, иллюстрации, поиск и подбор по ингредиентам; «Проверить GitHub» онлайн.
- Приготовление, независимые таймеры, пауза, поворот и возврат после сворачивания.
- Сигнал при выключенном экране не гарантирован: используйте системные «Часы».
- Покупки, дневник, оценки и фото после перезапуска в авиарежиме.
- Импорт рецепта, экспорт рецепта и полной копии, восстановление копии из Chrome.
- Выбор фото из галереи и файлового менеджера, отмена выбора и сохранения.
- Установка обновления поверх старой версии с сохранением данных.

Нативные тесты и lint: `cd android && ./gradlew :app:testDebugUnitTest :app:lintDebug`.
Для своей установленной версии Chromium: `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium npm run test:browser`.

В GitHub Actions workflow **Android APK** сохраняет APK как артефакт `moya-kuhnya-debug`.
Откройте запуск workflow → Artifacts → скачайте и распакуйте ZIP. Для скачивания нужно
войти в GitHub. Каждый чистый CI-runner создаёт собственную debug-подпись; для постоянных
обновлений собирайте локально с сохранённым keystore или настройте постоянную подпись CI.

## Версия 1.0.2

SystemBars обрабатывает системную строку, вырез экрана, навигационную панель и клавиатуру
нативными отступами. `viewport-fit=contain` оставляет весь WebView внутри безопасной области,
в том числе на старых WebView, где CSS env(safe-area-inset-*) ненадёжен. Дополнительно
над интерфейсом Android оставлено 6 px. Проверить на телефоне также поворот и открытие клавиатуры.
Иконка Android: контрастное блюдо на персиковом фоне, адаптивный вектор и монохромный вариант
для тематических значков, растровые варианты для старых Android. Исходник: assets/android-icon.svg.
