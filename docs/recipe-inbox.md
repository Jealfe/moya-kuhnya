# Как добавить рецепты из ChatGPT

## Через GitHub

1. Если у вас доступен режим агента или управление браузером в ChatGPT, используйте запрос ниже. При необходимости войдите в GitHub через окно браузера.
2. Когда JSON-файл появится в [папке recipes-inbox](https://github.com/Jealfe/moya-kuhnya/tree/main/recipes-inbox) в ветке `main`, откройте [каталог «Моей кухни»](https://jealfe.github.io/moya-kuhnya/#/recipes) в меню **⋯** нажмите **Проверить GitHub**. Для этого нужно подключение к интернету. Кнопка читает папку напрямую, поэтому ждать сборки GitHub Pages не нужно.
3. Новые рецепты появятся в каталоге на этом устройстве. На другом устройстве нажмите кнопку ещё раз. Уже сохранённые рецепты пропускаются по ID, включая ваши правки.

> Добавь 10 новых домашних рецептов в «Мою кухню». Открой https://github.com/Jealfe/moya-kuhnya и ознакомься с docs/recipes.md и каталогом public/data/recipes. Подбери блюда без повторов, сверь их с опубликованными рецептами, укажи источники и напиши пошаговые инструкции простым русским языком. Подготовь один JSON-набор версии 1 формата moya-kuhnya-recipes. У каждого блюда должен быть уникальный ID. В браузере GitHub создай один новый JSON-файл с уникальным именем в папке recipes-inbox ветки main. Вставь чистый JSON без Markdown и сохрани файл. Остальные файлы не меняй. Сообщи ссылку на созданный файл.

Папка публичная. Сохраняйте там только рецепты, которые готовы опубликовать.

## В обычном чате без доступа к записи

Попросите ChatGPT подготовить тот же JSON-набор и скопируйте его из ответа. В «Моей кухне» откройте **Рецепты → ⋯ → Импорт → Вставить из ChatGPT → Проверить текст**, проверьте предпросмотр и добавьте рецепты. Файл скачивать не требуется.
