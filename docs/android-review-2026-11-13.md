
# Проверка Android и рекомендаций GigaChat

13 ноября 2026 года

- **Исправлено.** Окно разбора сверяет рекомендации со снимком рецепта из записи дневника. Текущая карточка используется для старых записей без снимка.
- **Исправлено.** Завершившийся запрос сохраняет разбор в дневнике. Окно автоматически открывается только на исходном экране, если другое окно уже не открыто.
- **Исправлено.** Фон системных областей сверху и снизу согласован с темой. Системные кнопки, жесты и отступы для вырезов остаются доступны. Цвет и расположение стоит подтвердить на телефоне с жестами и с тремя кнопками навигации.
- **Добавлено.** Автокопия записывается в выбранную пользователем папку после изменения дневника. Два файла обновляются по очереди. Если запись прервётся, можно открыть предыдущую копию. Копия содержит фото и рекомендации, ключ GigaChat хранится отдельно. После переустановки потребуется выбрать файл и заново подключить папку.
- **Ограничение при установке.** Сборка CI выпускает отладочный APK. Для обновления с сохранением данных Android требует тот же сертификат подписи, которым подписан установленный APK. Перед установкой по USB нужно сравнить подписи. Если они различаются, сначала сохранить и проверить копию дневника.
- **Ограничение резервирования.** Восстановление принимает файлы до 256 МБ. При большом количестве фотографий автокопия покажет ошибку и сохранит предыдущую успешно записанную версию.
- **Проверки.** Тесты покрывают запрос по кнопке, валидацию ответов, отмену запроса, привязку совета к шагу, перенос отзывов, разборов и отметок. GigaChat и выбор папки в браузерной проверке имитируются. Живой запрос с ключом пользователя, системные полоски и перенос файла после удаления приложения проверяются на физическом устройстве.
