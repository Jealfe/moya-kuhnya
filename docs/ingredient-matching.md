
# Подбор рецептов из продуктов дома

Откройте **Рецепты → Что есть дома?**. Начните вводить продукт и выберите подсказку или вставьте список через запятую либо с новой строки. Вода, соль и растительное масло доступны для быстрого добавления. Чтобы удалить продукт, нажмите на него в разделе «Мой список». Приложение запоминает этот список в текущем браузере.

По кнопке **Подобрать рецепты** откроются три группы:

1. **Можно приготовить** — все продукты из рецепта отмечены.
2. **Не хватает одного продукта** — можно сразу увидеть, что докупить.
3. **Не хватает двух продуктов** — рядом с блюдом перечислены оба недостающих ингредиента.

В каждой группе первыми идут блюда, которые готовятся быстрее. Из карточки рецепта можно вернуться по ссылке **К подборке**.

Подбор работает без интернета со встроенными, личными и импортированными рецептами. Он узнаёт распространённые варианты названий вроде «картошка» и «картофель», учитывает «ё» и «е» и различает варёный и сырой рис, куриное филе и бёдра. Замену учитывает, только если она есть в справочнике приложения. Например, рафинированное подсолнечное масло подходит там, где указано растительное масло.

Проверьте количество по карточке рецепта. Список продуктов хранится в браузере и не входит в файл резервной копии.
