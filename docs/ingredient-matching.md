# Подбор рецептов из продуктов дома

## Как это будет выглядеть на телефоне

В каталоге под фильтрами будет отдельная кнопка «Что есть дома?». Она откроет окно снизу, почти на весь экран. Меню «⋯» останется для действий с файлами и рецептами.

1. Введите продукт. Приложение предложит названия из каталога, например «Яйца» или «Куриное филе». Для длинного списка можно вставить названия через запятую или с новой строки.
2. Добавленные продукты появятся отдельными плашками с кнопкой удаления. Вода, соль и масло будут доступны для быстрого добавления. Список сохранится на устройстве.
3. Нажмите «Подобрать рецепты». Сначала откроются блюда, для которых все продукты отмечены. Ниже появятся блюда, где не хватает одного или двух продуктов. На каждой карточке будет видно, что именно нужно докупить. Если подходящих блюд нет, окно предложит вернуться к списку продуктов.
4. Из результата можно открыть рецепт и вернуться к подборке с тем же списком продуктов. В результатах будет подсказка «Проверьте количество по рецепту».

## Как будет работать подбор

- Приводим названия к нижнему регистру, заменяем «ё» на «е» и убираем лишние пробелы. Общие варианты названий связываем вручную, например «репчатый лук» и «лук репчатый». «Куриное филе» и «куриные бёдра» считаем разными продуктами.
- Считаем, каких обязательных продуктов не хватает. Подтверждённую замену учитываем только после того, как она явно внесена в справочник соответствий. Свободный текст совета о замене показываем в рецепте.
- Сортируем по числу недостающих продуктов, затем по общему времени приготовления. Учитываем встроенные, свои и импортированные рецепты. Подбор работает офлайн.
- В первой версии пользователь отмечает наличие продуктов. Количества, единицы измерения, срок годности и автоматическое пополнение покупок можно проработать после проверки первого сценария.

## Проверка перед выпуском

На экране шириной 320 пикселей можно добавить и удалить продукты, открыть рецепт и вернуться к подборке. После перезагрузки список восстанавливается. Отдельно проверяем совпадения с «ё» и «е», точные синонимы, похожие продукты, пустой список, отсутствие совпадений и работу с импортированным рецептом без сети.
