# Моя кухня

Русскоязычное веб-приложение для обучения готовке. В каталоге 70 рецептов, пошаговый режим с независимыми таймерами, общий список покупок и дневник попыток с фотографиями. Рецепты, заметки и настройки хранятся в IndexedDB на устройстве.

## Запуск и проверка

Нужен Node.js 22 или новее. Устанавливать зависимости не требуется.

```sh
npm run dev
npm test
npm run build
npm run preview
```

Откройте адрес из вывода команды, обычно `http://127.0.0.1:4173/`. Для установки и проверки офлайн-режима используйте production-сборку через `npm run preview`. В режиме разработки Service Worker отключён.

Для проверки размещения в подкаталоге в PowerShell выполните `$env:KITCHEN_BASE='/kitchen'; npm run preview` и откройте `http://127.0.0.1:4173/kitchen/`.

## GitHub Pages

1. Загрузите проект в репозиторий GitHub, основная ветка — `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Запустите **GitHub Pages** в Actions или сделайте push в `main`. После публикации адрес появится в разделе Pages и в результате запуска.
4. Откройте адрес в Chrome на Android. Когда приложение загрузится, откройте **Настройки** и проверьте сообщение «Офлайн-доступ готов». Используйте кнопку установки или меню Chrome.

GitHub Pages раздаёт папку `dist`. Относительные пути и маршруты вида `#/recipe/pilaf` позволяют использовать любой подкаталог репозитория. Service Worker кэширует приложение и все встроенные рецепты при первом посещении. После новой публикации кнопка «Обновить» загружает готовую версию. Сначала сохраните открытый рецепт или отчёт.

## Рецепты и локальные данные

В покупках каждое добавление рецепта создаёт отдельный список с выбранным числом порций. Кнопка «Удалить блюдо» удаляет его целиком. Продукты, добавленные вручную, и покупки из предыдущей версии хранятся в общем списке. Копии версии 1 можно восстановить в этой версии.

- **Рецепты → Добавить рецепты → Проверить GitHub** добавляет новые блюда из папки `recipes-inbox` в ветке `main`. В импорте можно вставить JSON прямо из ответа чата. [Инструкция и запрос для ChatGPT](docs/recipe-inbox.md).
- В **Рецепты → Добавить рецепты → Импорт** выберите JSON одного рецепта или набора. Проверьте предпросмотр. При совпадении ID можно заменить рецепт, создать копию или пропустить запись.
- У встроенного рецепта «Редактировать» сохраняет личную версию под тем же ID. Исходные JSON остаются в каталоге приложения. Обновление сайта сохраняет пользовательские изменения.
- Экспорт карточки скачивает один JSON, а «Экспорт всех» скачивает набор. Описание полей, пример, JSON Schema и запрос для ChatGPT находятся в [документации формата](docs/recipes.md).
- В **Настройки → Скачать копию** сохраняются рецепты и фото, покупки, дневник, цели, настройки и текущая готовка с таймерами. Для восстановления откройте файл в настройках и подтвердите замену после предпросмотра. Данные браузеров и разных адресов сайта хранятся независимо.
- Для импорта и копий принимаются файлы до 256 МБ. Фото из редактора и дневника сжимаются перед сохранением. Формат резервной копии — единый JSON с изображениями внутри.
- Пауза готовки останавливает учёт времени приготовления, но оставляет запущенные таймеры активными. В фоне или после закрытия браузера звук зависит от ОС. Для надёжного фонового сигнала используйте системные «Часы».

У каждой встроенной карточки есть ссылка на опубликованный источник для сверки. Инструкции адаптированы для начинающих. Встроенные изображения — сгенерированные иллюстрации блюд. Температуры безопасной готовности сверены с [FoodSafety.gov](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures).
