# Новые рецепты для «Моей кухни»

Сохраняйте здесь файлы `.json` в UTF-8. Приложение читает эту папку в ветке `main` при нажатии **Рецепты → ⋯ → Проверить GitHub**. Для импорта подходят [один рецепт](../public/data/recipes/pilaf.json) и набор рецептов. Предпочтительно сохранять одну подборку в одном файле с новым именем, например `2026-11-11-dinners.json`.

Набор имеет структуру `{"format":"moya-kuhnya-recipes","version":1,"recipes":[...]}`. Для каждого блюда придумайте новый стабильный ID. [Формат и готовый запрос](../docs/recipes.md).

Рецепты добавляются локально по ID. Повторная проверка не создаёт копий и не заменяет уже существующие рецепты. Файлы с ошибками указываются в результате проверки. Поддерживаются JSON-файлы до 10 МБ в корне этой папки. Содержимое репозитория публичное.
